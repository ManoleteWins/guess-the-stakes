Reads PokerStars, GGPoker, partypoker, 888poker, Winamax, WPN / ACR, iPoker (XML) and Ignition / Bovada, plus tracker exports from PokerTracker and Holdem Manager. Anything else falls through to a loose reader that copes with most club-app and home-brew exports — if it has seats, blinds and actions, it will usually replay.

Everything runs in this page — hands are never uploaded anywhere, and there is no server to store them on. Share therefore sends the hands themselves, not a pointer to them: opened as its own page, it copies a link with the hands packed inside, and whoever opens that link gets the same hidden-stakes puzzle. Embedded in a viewer, where this page doesn't own its address bar, it copies the hands as text for the other person to paste into this box instead.
